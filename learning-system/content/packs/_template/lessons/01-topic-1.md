## 一、第一个学习点

### 先看一个错误/朴素的写法

```javascript
// ✗ 这样写会有什么问题？

  return 1;
}
```

问题在于：……

### 再看正确写法

```javascript
// ✓ 正确写法
function example() {
  return 1;
}
```

::: why 为什么要这样改
解释原理。不要只给结论，要讲"为什么"。
:::

不要说"注意边界"，要说"不这么做会报 XXX"。
:::
